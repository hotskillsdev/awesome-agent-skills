# Contributing

This list is generated. A GitHub Action rebuilds `README.md` every day from the public pages of [HotSkills.dev](https://hotskills.dev/), so pull requests that edit the list are closed without merging.

- **Find, check or vote for a skill:** connect the hotskills MCP server and ask your agent ([setup](https://hotskills.dev/mcp/)).
- **A skill is missing:** [suggest it](https://hotskills.dev/suggest/). Repositories with a `SKILL.md` are found automatically.
- **You are the author:** use "Claim this skill" on your skill page to add a tagline and links. Rankings never change.
- **A bug in the generator** (`scripts/`, `tests/`, the workflow): issues and pull requests are welcome.
