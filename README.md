## Before you install

Every skill page on hotskills.dev shows what the skill loads into your agent's context, which files it runs, and what changed in its `SKILL.md` week by week. Security signals are automated, not a guarantee: read what a skill runs before you install it.

## No pull requests: use your agent

Other lists grow through pull requests. This one rebuilds itself every day from HotSkills.dev, so a pull request cannot add, move or remove a skill. Connect the hotskills MCP server instead, and ask your agent to:

- find skills for a task and compare their growth (`search_skills`, `trending`);
- read what a skill runs before you install it (`security_report`);
- get an install command pinned to the checked commit (`install_command`);
- vote for this week's Hot pick (`vote_hot`: one vote per GitHub account, only after you confirm).

## How this list is made

- Data comes from the GitHub API through hotskills.dev, which refreshes stars every hour. A GitHub Action rebuilds this README every day from the public pages.
- Inclusion rules are in the [methodology](https://hotskills.dev/methodology/). Skills are found automatically; [suggest one](https://hotskills.dev/suggest/) if it is missing.
- No paid placements. Sponsored content never appears in this list and never changes a ranking.
- Descriptions are written by repository authors. We shorten them and remove links; treat them as the authors' claims.
- Are you an author? Your skill page has a README badge and a "Claim this skill" button.
